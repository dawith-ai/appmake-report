# appmake-report — docu · palette 출시 보고서

두 앱의 출시 상태를 한 페이지로 모은 보고서 사이트. 데모 빌드와 법적 페이지를 함께 담는다.

## 주요 기능

- 출시 보고 index — 루트 `index.html`에서 두 앱의 상태를 한눈에
- docu · palette 데모 빌드 동봉 — 각 앱의 실제 빌드 산출물을 그대로 배포
- 스토어 심사용 법적 페이지 4종 — `docu-privacy.html`·`docu-terms.html`·`palette-privacy.html`·`palette-terms.html`
- 앱 아이콘·아이콘 스프라이트 — 앱별 `favicon.svg`·`icons.svg`
- PWA manifest 포함
- 정적 서빙 — `.nojekyll`
